# Changelog

## 0.1.0

- Finder Quick Action generated and signed by the installer.
- Local Swift helper builds with Apple Command Line Tools; no Homebrew dependency.
- Configurable EPUB archive with cleaned names, preserved bytes/metadata, and Yellow tagging.
- Native Kindle share extension with verified title/author entry and automatic or review mode.
- Explicit send results, single-run locking, and source-change protection.
- Repeatable setup with staged app replacement, prior-version backups, tests, and macOS CI.
